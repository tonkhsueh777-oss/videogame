# 剑影 · 互动剧情

9:16 手机版互动影片网页。玩家观看影片，在关键节点进行二选一，进入不同分支与四个结局。

## 在线地址

https://tonkhsueh777-oss.github.io/videogame/

## 你只需要上传 7 段 MP4

请进入仓库的 `media/` 文件夹，把影片用下面 **完全相同的文件名** 上传：

| 剧情 | 文件名 |
| --- | --- |
| 开场：女剑客面对魔王 | `01_intro.mp4` |
| 分支 A：拔剑迎战 | `02A_fight.mp4` |
| 分支 B：退入遗迹 | `02B_escape.mp4` |
| 结局 A1：刺向核心 | `03A1_core.mp4` |
| 结局 A2：斩断石链 | `03A2_chain.mp4` |
| 结局 B1：启动封印 | `03B1_seal.mp4` |
| 结局 B2：冲过吊桥 | `03B2_bridge.mp4` |

上传完成后，网页代码会直接读取这些 MP4，不需要再修改程序。

## 互动结构

- 第一次选择：拔剑迎战 / 退入遗迹
- 战斗路线：刺向核心 / 斩断石链
- 遗迹路线：启动封印 / 冲过吊桥
- 四个结局
- 选择按钮约在影片播放至 6.4 秒时出现
- 结局可重新挑战或返回上一个选择

## GitHub Pages

仓库已包含 GitHub Pages 自动部署工作流。若 Pages 尚未开启，请到：

`Settings → Pages → Build and deployment → Source → GitHub Actions`

选择后保存。以后每次更新 `main` 分支都会自动重新部署。
